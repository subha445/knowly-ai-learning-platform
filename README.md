
💜 KNOWLY – AI Learning Platform

Learn Smarter. Grow Faster.

KNOWLY is a student-focused learning platform designed to make studying easier, more organised and interactive.

🌟 Features

- Smart Notes: Turn lesson text into quick revision notes.
- Practice Quiz: Generate simple practice questions and check answers.
- Research Assistant: Explore topics and find summaries.
- Learning Analytics: Track your learning activity.
- Flashcard Maker: Create question-and-answer flashcards.
- Study Timer: Use a 25-minute focus session and a 5-minute break.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Wikipedia REST API

🌐 Live Website

"Visit KNOWLY" (https://subha445.github.io/knowly-ai-learning-platform/)

🚀 How to Use

1. Open the KNOWLY website.
2. Select a learning tool from the dashboard.
3. Enter your lesson text or topic.
4. Use the available tools to study and revise.
5. Track your learning activity.

📱 Responsive Design

KNOWLY is designed to work on desktop and mobile screens.
